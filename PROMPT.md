## The two jobs, in order

### 1. Rebuild the wheel's emphasis model

Right now the edges read as "lit up all the time," and clicking a colour doesn't
separate the related structure from the rest clearly enough. The cause is that
emphasis is carried entirely by one opacity value, tuned in both directions
until the range collapsed.

Restructure it so emphasis comes from several channels at once:

- At rest, edges are quiet — around 0.45 opacity, thin.
- Selected/related: full opacity, thicker stroke, and a soft glow
  (`filter: drop-shadow(...)`) so it reads as lit rather than merely darker
  surroundings.
- Unrelated: drops to roughly 0.22 — receded but still legible, because the far
  side of the wheel shouldn't disappear when I click White.

The point is that the gap between states comes from width and glow as much as
alpha, so neither end has to be extreme. Tune it live with me; don't guess at
final numbers.

### 2. Make clicking a colour feel like something

This is the part that should be genuinely good. When I click Green it should do
something worth watching once.

The mechanism I want is an SVG draw-on: `stroke-dasharray` plus animated
`stroke-dashoffset`, so the edges connected to the clicked vertex draw
themselves outward from that vertex. One shot, roughly 600ms, then still. Not a
loop, not ambient.

Give each colour its own character through easing and direction rather than five
different effects:

| Colour | Feel | Direction / easing |
|---|---|---|
| White | Order | both edges draw symmetrically, in unison |
| Blue | Deliberation | slow ease-in-out, arriving last |
| Black | Acquisition | draws *inward*, toward the vertex |
| Red | Impulse | fast, near-instant, slight overshoot |
| Green | Growth | draws outward, decelerating as it lands |

That mapping comes from my own product notes; it isn't invented. See CONTEXT for
the underlying source.

Non-negotiable: honour `prefers-reduced-motion` by **skipping the animation
entirely**, not by slowing it. The current file already does this correctly
elsewhere — match that pattern.
