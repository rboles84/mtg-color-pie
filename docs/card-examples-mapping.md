# Mechanical Color Pie: which example goes on which page entry

A one-to-one map from `docs/card-examples-collection.md` to the entries on the explorer page (`vox-color/mechanical-explorer.html`). No card lookups are involved; it is the collection joined to the page. Compiled 2026-10-09. Nothing was changed on the page or in the data.

**How it was checked.** I read the entries off the running page, not only the data file. The page shows 216 entries. Their keys, label text, order and section headings match the collection's numbering exactly, so every collection row lands on exactly one page entry and every page entry has exactly one row. The `Key` column is the page's own entry key.
